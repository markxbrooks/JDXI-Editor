Editor Tabs and Tools
====================

JD-Xi Editor presents its main sound-design and performance workspaces as tabs
in the editor area. Open an editor from the instrument interface, then select
its tab to work with that part of the instrument. Tabs within an editor organize
related controls, such as presets, synthesis sections, effects, and mixers.

The editor tabs include the Digital Synth editors for Parts 1 and 2, the Analog
Synth editor, Drum Kit editor, Effects editor, Vocal Effects editor, Arpeggiator
editor, Pattern Sequencer, and MIDI File Player. See :doc:`editor-windows` and
:doc:`additional-editors` for descriptions.

Some supporting tools, such as MIDI configuration and monitoring dialogs, still
open in separate windows. In this guide, “editor tab” means a workspace in the
main editor area; “window” means a separate application window or dialog.

To use an editor, open the relevant workspace from the instrument interface and
select its tab. Connect the JD-Xi when hardware communication is needed.
Available controls and hardware read/write behavior vary by editor; see
:doc:`usage` for connection and operation details.
